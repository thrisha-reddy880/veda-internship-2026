# 🎓 Student Grade Calculator

## 📌 Task

**Veda Technology – Java Programming Track**

### Task 2: Create a Student Grade Calculator

Build a Java program that accepts marks for multiple subjects, calculates total marks, percentage, and grade.

---

## 📝 Description

The **Student Grade Calculator** is a simple Java console-based application that allows users to enter student details and marks for multiple subjects.

The program automatically:

- Accepts the student's name
- Accepts the number of subjects
- Takes marks for each subject
- Validates the entered marks
- Calculates total marks
- Calculates percentage
- Determines the grade
- Displays the final result
- Displays pass/fail status

This project was created as part of the **Veda Technology Java Programming Internship**.
