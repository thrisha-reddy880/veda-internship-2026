# 🎯 Number Guessing Game

## 📌 Project Overview

The Number Guessing Game is a simple Java console application where the computer generates a random number between 1 and 100.

The user has to guess the number. After every attempt, the application provides a hint indicating whether the correct number is higher or lower than the user's guess.

The game continues until the user correctly guesses the number.

---

## 🎯 Objective

The objective of this project is to understand and implement:

- Random number generation
- User input using Scanner
- Loops
- Conditional statements
- Variables
- Attempt counting
- User interaction

---

## 🛠️ Technologies Used

- Java
- Java Random class
- Java Scanner class
- VS Code / IntelliJ IDEA
- Git & GitHub

---

## ✨ Features

- 🎲 Random number generation
- 🔢 Number range from 1 to 100
- ⬆️ Higher hint
- ⬇️ Lower hint
- 🎯 Correct guess detection
- 🔢 Attempt counter
- ⚠️ Invalid input handling
- 🔁 Continuous guessing until the answer is found
