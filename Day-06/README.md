# 🔄 Palindrome Checker

## 📌 Project Overview

The Palindrome Checker is a simple console-based Java application that
checks whether a given string or number reads the same forward and
backward.

The program supports both string and number palindrome checking.

---

## 🎯 Objective

The objective of this project is to practice:

- Strings
- Loops
- Character manipulation
- Conditional statements
- Methods
- User input
- Number manipulation

---

## ✨ Features

- 🔤 String palindrome checking
- 🔢 Number palindrome checking
- 🔠 Case-insensitive string checking
- 🔄 Character comparison from both ends
- 🖥️ Console-based interface
- 🛠️ Separate methods for string and number checking

---

## 🛠️ Technologies Used

- Java
- Scanner
- Strings
- Loops
- Conditional statements
- Methods
