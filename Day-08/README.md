# 🏧 Simple ATM Simulation

## 📌 Project Overview

The Simple ATM Simulation is a console-based Java application that
simulates basic ATM operations.

The application provides PIN authentication and allows the user to
check their balance, deposit money, withdraw money, and exit the
application.

---

## 🎯 Objective

The objective of this project is to practice:

- Conditional statements
- Loops
- Methods
- User input
- State management
- Basic transaction handling
- Input validation

---

## ✨ Features

- 🔐 PIN authentication
- 🔢 Limited PIN attempts
- 💰 Balance checking
- ➕ Deposit functionality
- 💸 Withdrawal functionality
- ⚠️ Insufficient balance handling
- ⚠️ Invalid transaction handling
- 🚪 Exit option
- 🔄 Menu-driven interface

---

## 🛠️ Technologies Used

- Java
- Scanner
- Methods
- Loops
- Conditional statements
