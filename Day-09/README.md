# 🏦 Simple Banking Account System in Java

## 📌 Project Overview
This project implements a simple banking account system using Java. It allows users to perform basic banking operations through an interactive menu.

## 🎯 Objectives
- Understand classes and objects.
- Practice constructors and methods.
- Implement encapsulation using private fields.
- Validate deposits and withdrawals.

## ✨ Features
- Create a bank account with account number and holder name.
- Deposit money into the account.
- Withdraw money with balance validation.
- Check the current account balance.
- Display account details.
- Interactive menu with input validation.

## 🛠️ Technologies Used
- **Programming Language:** Java
- **Concepts:** Object-Oriented Programming (OOP)
- **Tools:** Any Java-compatible IDE or online compiler

## ▶️ How to Run
1. Install Java or open an online Java compiler.
2. Create a file named `Main.java`.
3. Copy the Java source code into the file.
4. Compile and run the program.
5. Follow the on-screen menu to perform banking operations.
