# 📚 Multiplication Table Generator

## 📌 Project Overview

The Multiplication Table Generator is a simple console-based Java
application that generates multiplication tables.

The program can generate a table for a single number or generate
multiple multiplication tables for a given range of numbers.

---

## 🎯 Objective

The main objective of this project is to practice:

- Java loops
- Nested loops
- Methods
- User input
- Conditional statements
- Formatted console output

---

## ✨ Features

- 🔢 Single-number multiplication table
- 📊 Range-based multiplication tables
- 🔁 Nested loops
- 🛠️ Separate methods for table generation
- ⚠️ Input validation for range
- 🖥️ Formatted console output

---

## 🛠️ Technologies Used

- Java
- Scanner
- For loops
- Nested loops
- Methods
- Conditional statements
