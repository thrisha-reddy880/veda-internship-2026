# 🔢 Prime Number Analysis

## 📌 Project Overview

Prime Number Analysis is a console-based Java application that checks
whether a number is prime and generates prime numbers up to a given
limit or within a specified range.

The project focuses on loops, mathematical logic, methods, and
algorithmic thinking.

---

## 🎯 Objective

The objective of this project is to practice:

- Java loops
- Mathematical operations
- Conditional statements
- Methods
- Prime number logic
- Range-based processing
- Algorithm optimization

---

## ✨ Features

- 🔍 Prime number checker
- 🔢 Prime number generator
- 📊 Range-based prime analysis
- ⚡ Optimized prime checking
- ⚠️ Handles numbers less than 2
- 🖥️ Console-based interface

---

## 🛠️ Technologies Used

- Java
- Scanner
- Loops
- Conditional statements
- Mathematical operations
- Methods
