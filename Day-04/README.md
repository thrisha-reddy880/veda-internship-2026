# 🎓 Student Management System Using Arrays

## 📌 Project Overview

The Student Management System is a simple console-based Java application
that manages student records using arrays.

The system allows users to add, search, update, and display student
information through a menu-driven interface.

---

## 🎯 Objective

The main objective of this project is to practice:

- Java arrays
- Methods
- Loops
- Conditional statements
- User input
- Linear search
- Basic CRUD operations

---

## ✨ Features

- ➕ Add student
- 🔍 Search student by ID
- ✏️ Update student details
- 📋 Display all student records
- 🆔 Unique student IDs
- ⚠️ Invalid student ID handling
- 🚪 Exit option
- 📱 Simple console-based interface

---

## 🛠️ Technologies Used

- Java
- Java Scanner
- Arrays
- Loops
- Methods
- Conditional Statements
